本项目参考 CFA 官方知识地图组织研究，结合中国披露和政策环境形成独立实现，不复制课程材料、不宣称认证。状态“可执行”表示有运行路径和验证；“受限”表示只能完成限定子集，不能将方法目录当成完整金融业务能力。

## 稳定方法

14 个 Skill 位于 `investment_agent/skill_methods/`。输入输出、单位、缺失规则和版本可通过 Agent 的 professional_catalog / professional_method 读取。计算统一输出数据、方法版本、假设、来源、时点与限制。固定模型不需要模型临时发明公式。

三表模型使用明确基期与逐年驱动，检查期初平衡、营运资本、折旧、资本开支、债务、权益与现金。融资缺口不自动补平。FCFF 输出企业价值，FCFE/DDM 输出股权价值；股权桥接单独处理现金、债务、少数股东和估值日股数。所有前瞻输入都是假设，不能自动标成公司指引。

工作台可编辑假设后直接重算。默认操作数值仅演示，不是公司预测；缺少基期或依据时阻止计算。非金融年度模型假设其他资产负债保持不变，不能直接用于银行、保险或复杂重组。

## 中国市场

政策调查区分征求意见、正式文件、预算、细则与执行，必须连接公司真实业务敞口和财务兑现条件。会计检查合并/母公司、归母/少数股东、扣非、累计/单季、政府补助、研发资本化、客户集中、关联担保、受限资金与审计意见。

交易研究使用已有真实交易日、复权、停复牌及涨跌停数据能力。严格回测缺少必要执行限制时拒绝运行；没有编造一套常量覆盖所有板块。当前没有完整版本化的全市场交易规则数据库。现时成分不能用于声称无幸存者偏差的历史行业回测。

## 验证

离线测试包括：三表手算样例、资金缺口、期初不平、FCFF/股权桥接、FCFE/DDM、剩余收益、ROIC、CAPM/WACC、回归、压力情景、季度/TTM和披露时点、缺失与负利润、模型预算、任务互斥、停止/恢复、熔断、上游模板离线可用，以及已有情报/数据/界面测试。

真实公开数据抽查使用工业富联：取得 23 个报告期、6 个年度和 20 条官方报告记录，最近完整年报的部分三表字段及附注解析成功。它证明该公司该次链路可用，不代表所有上市公司或全部附注均解析成功。原始财报与本机诊断日志不随仓库发布。

仍需逐步扩展的深度能力：扫描财报 OCR、不同年报版式的全面附注解析、逐版本宏观/财务历史库、金融企业专用模型、完整行业样本的长期样本外验证、自动跟踪每个研究判断的失效条件。当前产品会显示这些缺口，不冒充已完成。
