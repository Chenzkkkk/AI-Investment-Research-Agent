# 敞口压力测试

版本1.0.0。输入 exposures 为因子到净敞口金额（人民币元）的字典；shocks每项含name、changes字典和basis。
公式：各项损益=对应净敞口×变动率；总损益为各项之和。利率情景需先将债务久期或净利息敏感性转换为相应敞口，不能把债务本金直接当债券价格敏感度。
变化率为小数，每个因子都必须提供冲击。需要将外币敞口先按明确汇率转换为人民币，保持口径一致。
不处理非线性期权、经营调整、相关性、套保基差及动态交易。名义本金不等于净敞口。
方法参考：https://www.cfainstitute.org/programs/cfa-program/candidate-resources/cbok
验证：tests/test_professional_models.py。压力测试不是概率预测。

验收口径：计算用独立手算样例；比例/回归用约1e-8浮点容差，三表平衡使用金额绝对0.01元或相对1e-8。定性调查不使用数值误差，需逐项记录事实/观点/假设与来源；无正文不得标已核查。

变更记录：1.0.0 首次注册，计算与证据调查分离。输入缺失、来源冲突或方法不适用须明确返回，不回填零。
