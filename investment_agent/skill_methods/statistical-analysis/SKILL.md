# 统计与回归

版本1.0.0。输入 features 为行=观测、列=变量的二维矩阵，target为等长目标序列，feature_names可选。
通过 NumPy 最小二乘计算含截距OLS；拒绝缺失、无穷、秩不足、目标常数、样本数不足。
输出截距、系数、R²、样本量；样本内拟合不等于预测能力，不自动生成p值或因果结论。
时间序列需核对公布时点、平稳性、趋势、滞后与训练/验证划分。不能使用未来财务数据预测过去收益。
公式：最小化残差平方和；R²=1−残差平方和/总离差平方和。
方法参考：https://www.cfainstitute.org/programs/cfa-program/candidate-resources/cbok
验证：tests/test_professional_models.py。所有输入均需本轮证据或标注为假设。

验收口径：计算用独立手算样例；比例/回归用约1e-8浮点容差，三表平衡使用金额绝对0.01元或相对1e-8。定性调查不使用数值误差，需逐项记录事实/观点/假设与来源；无正文不得标已核查。
